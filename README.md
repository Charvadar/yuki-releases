# Yuki

A little white kitten that lives on top of your Mac's windows: she walks, jumps, hides, chases your cursor and copies what you do.

This repository only holds **Yuki's downloads and update feed**. There is no source code here.

- **Download:** the latest `Yuki-x.y.dmg` under [Releases](../../releases/latest). Open it and drag Yuki into Applications. Needs macOS 14 or newer (Apple silicon or Intel).
- **Updates:** Yuki checks `appcast.xml` here about every 6 hours. When there's a new version, she'll ask you herself; click her to update. Turn this off in her menu bar menu (🐈 → "Check for updates automatically").

Every build is signed with a Developer ID, notarized by Apple, and every update is signed with Yuki's own update key.
